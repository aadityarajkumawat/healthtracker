# Next.js starter

A minimal Next.js App Router template deployed at [nextjs-app-amber-three.vercel.app](https://nextjs-app-amber-three.vercel.app).

## Run locally

Use Node.js 22.13 or newer, then run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Edit `app/page.tsx` for the home page and `app/globals.css` for its styles.
